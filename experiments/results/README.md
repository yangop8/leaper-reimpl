# Results

Committed: the per-second time series (`*.timeseries.csv`), the background
operation timelines (`*.events.csv`), the figures (`*.png`) and the phase
calibrations (`*.calibration.txt`). These are the measurements the documents in
`docs/` report.

Not committed, because they are machine-generated and regenerated by the
experiment scripts: trained models (`*.model.*`), oracle hot sets
(`*.oracle.txt`), raw access traces (`*.trace.*`) and LevelDB info logs
(`*.leveldb.log`). Together they are ~15 MB of text that a five-minute training
run reproduces.

Prefixes map to regimes:

| prefix | regime |
|---|---|
| `m0_A_8t`, `m0_B_2t`, `m0_C_ro` | does the phenomenon exist on stock LevelDB (C is the no-background-operations control) |
| `m4_nvme` | LevelDB baseline matrix, NVMe |
| `m4_slow` | LevelDB baseline matrix, emulated 200 us device |
| `m4_sparse` | as above with 1000 key ranges (~3% hot) |
| `m4_r10`, `m4_r3`, `m4_r1` | cache/data ratio sweep, 10% / 3% / 1% |
| `m4_corr05`, `m4_corr02` | read/write hot-set correlation sweep |
| `m4_heavy` | write-heavy operation mix |
| `m7` | RocksDB baseline matrix |
